Contacter l’assistance

Pour nous aider à vous répondre

Lorsque vous nous contactez, vous pouvez préciser :

  • le modèle de votre appareil ;
  • la version d’iOS ou d’iPadOS utilisée ;
  • la version d’AllCollect ;
  • une description du problème rencontré ;
  • les étapes permettant de reproduire le problème, si possible.

Synchronisation iCloud

Si votre demande concerne la synchronisation iCloud, vérifiez que vous êtes connecté au même compte Apple sur vos appareils et qu’iCloud est activé pour AllCollect.
